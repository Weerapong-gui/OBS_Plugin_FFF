# OBS_Plugin_FFF — FFF Tools for OBS

Plugin ของสโมสรนักศึกษา มฟล. สร้างจาก [obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate)

มีอะไรข้างใน (v0.3.0):
- **FFF Flag Board** — dock คุมกระดานผลการออกธงของนายกแต่ละสำนักวิชา คนดูกดสีธงจากมือถือ ผลขึ้นจอสตรีมผ่าน Browser Source: เมนู Docks → FFF Flag Board
- **FFF Tint** — video filter ย้อมสีภาพ (ตัวอย่างโครง filter): คลิกขวาที่ source → Filters → + → FFF Tint

## ติดตั้ง

โหลดไฟล์จาก [Releases](https://github.com/Weerapong-gui/OBS_Plugin_FFF/releases)
ต้องมี **OBS Studio 30 ขึ้นไป** และต้องปิด OBS ก่อนติดตั้งทุกครั้ง

| OS | ไฟล์ | วิธี |
|---|---|---|
| macOS (Apple Silicon + Intel) | `fff-tools-<version>-macos-universal.pkg` | ดับเบิลคลิก ติดตั้งลง `~/Library/Application Support/obs-studio/plugins` |
| Windows x64 | `fff-tools-<version>-windows-x64.exe` | ตัวติดตั้ง ลง `%ProgramData%\obs-studio\plugins` (ขอสิทธิ์ admin) |
| Linux (Ubuntu 24.04 x86_64) | `fff-tools-<version>-x86_64-linux-gnu.deb` | `sudo apt install ./fff-tools-<version>-x86_64-linux-gnu.deb` |

Windows มี `fff-tools-<version>-windows-x64.zip` ให้ด้วยถ้าไม่อยากใช้ตัวติดตั้ง
— แตกแล้วเอาโฟลเดอร์ `fff-tools` ไปวางในโฟลเดอร์ plugins ของ OBS เอง
macOS และ Linux มีเฉพาะตัวติดตั้ง — release ที่แนบไฟล์ติดตั้งมาด้วยจะไม่ได้ทำ `.tar.xz` คู่กัน
(`fff-tools-<version>-source.tar.xz` คือซอร์สโค้ด ไม่ใช่ปลั๊กอินที่ build แล้ว)

### ติดตั้งแล้วได้อะไรมาเลย

เครื่องที่ยังไม่เคยมีปลั๊กอินนี้ เปิด OBS มาจะได้กระดานที่พร้อมใช้เลย — รายชื่อ 14 สำนักวิชา
พร้อม PNG ทุกสถานะ โลโก้ Cover ตำแหน่งทุกชิ้น แม่แบบ และจังหวะ animation
ชุดเดียวกันกับเครื่องที่ใช้งานจริง

สิ่งที่**ไม่**ติดมาด้วย เพราะเป็นของเฉพาะเครื่องและเฉพาะงาน: **PIN ถูกสุ่มใหม่ทุกสำนัก**
ตอนเปิดครั้งแรก (ดูได้ในแท็บ **รายชื่อ**) · Monitor LAN เริ่มที่ปิดและยังไม่มีกุญแจ
· รอบเริ่มที่ 1 จอว่าง ไม่มีผลโหวตติดมา

อยากเริ่มจากศูนย์เอง ให้ลบรายชื่อออกจากแท็บ **รายชื่อ** หรือปิด OBS แล้วลบ `session.json`
ในโฟลเดอร์ config (path อยู่ท้ายหน้านี้) — เปิดใหม่แล้วชุดค่าเริ่มต้นจะกลับมาเอง

### macOS: การ์ดขึ้นว่า "ไม่สามารถเปิดได้"

`.pkg` **ไม่ได้เซ็นและไม่ผ่าน notarization** (โปรเจกต์นักศึกษา ไม่มี Apple Developer account)
Gatekeeper จึงบล็อกไว้ มีสองทาง:

1. ดับเบิลคลิกไฟล์ จะขึ้นว่าเปิดไม่ได้ → ไปที่ System Settings → Privacy & Security → เลื่อนลงล่างสุด → **Open Anyway**
2. หรือสั่งเองก่อนเปิด:

```sh
xattr -dr com.apple.quarantine ~/Downloads/fff-tools-*-macos-universal.pkg
```

### Linux

`.deb` ถูก build กับ OBS จาก `ppa:obsproject/obs-studio` ถ้าใช้ OBS จาก Flatpak หรือ Snap ปลั๊กอินจะไม่ถูกโหลด:

```sh
sudo add-apt-repository ppa:obsproject/obs-studio
sudo apt update && sudo apt install obs-studio
```

### เช็คว่าโหลดสำเร็จ

เปิด OBS → Help → Log Files → View Current Log ต้องเจอ:

```
[fff-tools] plugin loaded successfully (version 0.3.0)
[fff-tools] flag board listening on port 9779
```

ปลั๊กอินเปิด HTTP server บนเครื่องที่ติดตั้ง (ค่าเริ่มต้นพอร์ต 9779) เปลี่ยนพอร์ตได้ในแท็บตั้งค่าของ dock

## Flag Board ทำงานยังไง

```
มือถือคนดู (n เครื่อง)               Mac ที่รัน OBS
┌──────────────┐  POST /api/vote  ┌─────────────────────────┐
│ ชื่อ/สำนักวิชา │ ───────────────> │  HTTP server ในปลั๊กอิน  │
│ [แดง][เขียว] │ <──── SSE ────── │  + สถานะรอบปัจจุบัน       │
└──────────────┘                  └─────────────────────────┘
                                             │ SSE
                              Browser Source ▼ http://127.0.0.1:9779/overlay
```

- ปลั๊กอินเปิด HTTP server เองบนเครื่อง Mac คนดูเข้าเว็บที่ปลั๊กอินเสิร์ฟ ใส่ PIN ของตัวเอง แล้วกดสีธง
- **จอสตรีมว่างเปล่าสนิทจนกว่า operator จะกด Show Status หรือ BOTTOM BAR** — ครบทุกคนแล้วก็ยังไม่ขึ้นเอง บรรทัดสรุปใต้แถบสถานะจะเป็นสีเขียวว่า `✓ ครบ X/Y พร้อมขึ้นจอ` บอกว่าถึงจังหวะ จังหวะขึ้นจอเป็นของคนคุมงานล้วน ๆ
- กดตอนยังไม่ครบก็ได้ การ์ดของคนที่ยังไม่กดยังคงเป็น PNG หรือกรอบโปร่งใสเดิม
- หลังผลขึ้นแล้ว คนดูยังเปลี่ยนสีได้ จอเปลี่ยนตามทันที
- กด **↻ เริ่มรอบใหม่…** ที่ dock แล้วยืนยัน เพื่อล้างผลโหวตและขึ้นรอบถัดไป จอกลับไปว่าง รายชื่อ การ์ด PNG และ PIN ยังอยู่ครบ

### BOTTOM BAR

Browser Source `/overlay` เดิมสลับได้ทันทีด้วยปุ่ม **Show Status** และ **BOTTOM BAR** ในแถบไลฟ์ด้านบนของ dock โดยใช้รอบ รายชื่อ และผลโหวตร่วมกัน แถบนี้ปักอยู่เหนือแท็บ ไม่เลื่อนหายไปกับเนื้อหา

ปุ่มโหมดเป็น toggle: กดตอนจอว่างเพื่อขึ้นจอ กดอีกโหมดเพื่อสลับ กดโหมดที่ออกอากาศอยู่ซ้ำเพื่อลงจอ มีได้ครั้งละหนึ่งโหมด ปุ่มที่ออกอากาศเป็นพื้นสีฟ้า แถบสถานะบนสุดบอกทั้งคำและสี: แดง `● ออกอากาศ · BOTTOM BAR`, เทา `○ จอว่าง`, เหลือง `⚠ เซิร์ฟเวอร์ปิด`

กด **■ ซ่อนจอ** เพื่อ **ซ่อนภาพอย่างเดียว** รอบ ผลโหวต และโหมดที่เลือกไว้ยังอยู่ครบ กดขึ้นใหม่ได้ทันทีด้วยรอบเดิม ต่างจาก **↻ เริ่มรอบใหม่…** ที่ถามยืนยันก่อน แล้วล้างผลโหวตและขึ้นรอบถัดไป

ในแท็บ **รายชื่อ** เลือกแถวสำนักแล้วใช้เมนู **PNG** เพื่อนำเข้าหรือลบ **BOTTOM BAR PNG** และ **โลโก้กลาง Round 1 / Round 2 PNG** แยกจากการ์ด Show Status จากนั้นในแถบไลฟ์เลือกชุดโลโก้ด้วยปุ่ม **Round 1** / **Round 2** และเลือกสำนักจากรายการ **สำนัก** (หรือไม่เลือกโลโก้) ถ้าเลือก Round 2 แต่สำนักนั้นยังไม่มี PNG ของ Round 2 ช่องโลโก้บนจอจะว่าง และแถบไลฟ์ขึ้นคำเตือนสีเหลือง Round ของโลโก้ไม่เกี่ยวกับตัวนับรอบโหวต การเลือกนี้ไม่เปลี่ยนรายชื่อหรือผลโหวต

PNG ที่ใหญ่เกิน 1920×1080 ถูกย่อให้พอดีกรอบนั้นก่อนส่งให้ overlay และ monitor (เก็บไว้ที่ `cards/renditions/` ไฟล์ต้นฉบับที่นำเข้าไม่ถูกแตะ) เพราะไฟล์ขนาด 4500×8000 ต้องคลายภาพถึง 144 MB ต่อใบ ทำให้การขึ้นจอครั้งแรกค้างราวครึ่งวินาที การย่อทำเบื้องหลังทันทีที่นำเข้าหรือเปิด OBS ใบละไม่ถึงครึ่งวินาที และทำครั้งเดียวต่อไฟล์ ถ้ากดขึ้นจอระหว่างที่ยังย่อไม่เสร็จ ภาพใบนั้นจะตามมาเมื่อย่อเสร็จ

**Cover PNG** เป็นภาพส่วนกลางของ BOTTOM BAR เลือกหรือลบได้ในแท็บ **ตั้งค่า** ของ dock โดยไม่ต้องเลือกสำนัก แนะนำ PNG โปร่งใส 1920×1080 ภาพเริ่มต้นอยู่กลางเต็มจอและหน้าสุด สัดส่วนอื่นแสดงเต็มภาพโดยไม่ครอปหรือบิด หากไม่มีไฟล์จะไม่มีภาพเพิ่มบนจอสตรีม เลือก Cover จากรายการชิ้นงานในมอนิเตอร์เพื่อย้าย ปรับขนาด ลำดับ และ opacity 0–100% หรือรีเซ็ตกลับเต็มจอ Cover ไม่รับค่า opacity จากแม่แบบช่องธง และไม่อยู่ในแม่แบบทุกช่อง

เมื่อแสดง BOTTOM BAR โลโก้เฟดพร้อมขยับขึ้น 12px ใน 240ms และ Cover เฟดอย่างเดียว 400ms การ์ดเปิดจากล่างขึ้นบนพร้อมขยับขึ้น 18px ใน 600ms เริ่มคู่ด้านในที่ 100ms แล้วไล่ออกด้านข้างคู่ละ 60ms (stagger สูงสุด 560ms) ใช้ easing `cubic-bezier(0.22, 1, 0.36, 1)` จำนวน 14 สำนักจบที่ 1060ms และจำนวนมากไม่เกิน 1260ms แถบสีโหวตสูง 12px เคลื่อนตามขอบเปิดภาพและหายเมื่อจบ เคารพ result opacity; ยังไม่โหวตเปิดเฉพาะ artwork ไม่มีแถบสี การแก้ภาพ สี หรือ layout ไม่เริ่ม intro ใหม่

เมื่อลงจอ เริ่มรอบใหม่ หรือสลับโหมด การ์ดเฟดพร้อมเลื่อนลงอีก 12px ใน 320ms จากสภาพที่กำลังแสดง โลโก้และ Cover เฟดอย่างเดียว ตรึง artwork และสีรอบเดิมไว้จนออกจบ แล้วแสดงสถานะล่าสุด รวมถึงกรณี Clear แล้ว reveal ทันที มอนิเตอร์แสดงตำแหน่งปลายทางแบบนิ่ง ไม่มี motion หรือ clipping ชั่วคราว

เมื่อแสดง Show Status การ์ดเลื่อนเข้าจากซ้ายไปขวาพร้อมจางเข้าทีละใบตามลำดับรายชื่อ ใบละ 600ms ห่างกันใบละ 120ms (ทั้งชุดเริ่มครบภายใน 1.2 วินาที) เมื่อลงจอ เริ่มรอบใหม่ หรือสลับโหมด การ์ดเลื่อนต่อไปทางขวาพร้อมจางหายทีละใบ ใบละ 320ms ห่างกันใบละ 60ms (ภายใน 0.6 วินาที) แล้วจึงแสดงโหมดถัดไป การ์ดที่เปลี่ยนสถานะระหว่างออกอากาศยังเด้งเฉพาะใบนั้นเหมือนเดิม

ค่าเริ่มต้น BOTTOM BAR อยู่ล่างผืนงาน 1920×1080 สูง 250px เว้นกลางกว้าง 220px จำนวน 14 สำนักแบ่งเป็น 7+7 และจำนวนคี่ให้ฝั่งซ้ายมากกว่าหนึ่งช่อง PNG คงความโปร่งใส สีธงอยู่หลังภาพและซ่อนเมื่อยังไม่โหวต ไม่มีพื้นหลังหรือชื่อซ้ำเพิ่มให้ โลโก้แสดงเต็มภาพโดยรักษาสัดส่วน

ในจอมอนิเตอร์เลือกโหมดแก้ไขได้โดยไม่เปลี่ยนโหมดออกอากาศ แต่ละโหมดบันทึกตำแหน่ง ขนาด ลำดับเลเยอร์ และแม่แบบแยกกัน ปรับ opacity ของ PNG/สีธงรายช่องหรือร่วมผ่านแม่แบบได้ รวมถึง opacity โลโก้กลาง การรีเซ็ตตำแหน่งมีผลเฉพาะโหมดที่เลือก

### หน้า Score (`/score`)

Browser Source อีกหน้าหนึ่ง แยกจาก `/overlay` โดยสิ้นเชิง: พื้นหลังโปร่ง มีหัวเรื่อง (ค่าเริ่มต้น **พี่เนย**) กับตัวเลขจำนวนธงแดงและธงเขียว **หน้านี้ไม่เคยว่าง** — นับสดตั้งแต่ธงใบแรกที่กดเข้ามา ไม่รอปุ่ม Show Status หรือ BOTTOM BAR และไม่เกี่ยวกับ `displayMode` ใด ๆ ตัวเลขหมุนแล้วลงเลขใหม่แบบเดียวกับตัวนับใน BOTTOM BAR

เพิ่มเป็น Browser Source ขนาด 1920×1080 ชี้ที่ `http://127.0.0.1:9779/score` (คัดลอกลิงก์ได้จาก dock แท็บ **ตั้งค่า**) หน้านี้เห็นผลก่อนออกอากาศเหมือน `/monitor` จึงเปิดได้จากเครื่องนี้เสมอ ส่วนเครื่องอื่นใน LAN ต้องมีกุญแจ monitor (ดูหัวข้อถัดไป — ลิงก์ `Score` อยู่คู่กับลิงก์ `Monitor`)

หน้าตา: **แผ่นป้ายทึบ** รองทุกชิ้น เพราะพื้นหลังคือวิดีโอสดอะไรก็ได้ จะหวังพึ่งฉากข้างหลังให้อ่านออกไม่ได้ — บนสุดเป็นแผ่นหัวเรื่อง ถัดมาเป็นแผ่นตัวนับสองใบ **เขียวซ้าย แดงขวา** ขอบสีตามธง พร้อมป้าย **เขียว** / **แดง** ใต้เลข เผื่อคนที่เพิ่งเปิดเข้ามาจะได้รู้ว่าเลขไหนคือธงสีอะไรโดยไม่ต้องเดาจากสี สีธงอยู่ที่ขอบ ตัวเลข และป้ายเท่านั้น พื้นเป็นสีเข้มทึบเสมอ

ป้ายกำกับ แผ่นป้าย และระยะห่างทั้งหมด **ตายตัวใน `app.css`** แก้จากหน้า monitor ไม่ได้ ที่แก้ได้คือหัวเรื่องกับตัวเลขเท่านั้น (แผ่นป้ายหัวเรื่องเดินตามกล่องที่ตั้งไว้ ย้ายหรือขยายกล่องแล้วแผ่นขยับตาม)

แก้หัวเรื่องและตัวเลขได้ที่แท็บ **หน้า Score** ในจอมอนิเตอร์: ข้อความ กล่อง X/Y/กว้าง/สูง ความทึบ ฟอนต์ น้ำหนัก ขนาด ระยะบรรทัด การจัดชิด และสี — ตัวเลขธงแก้ฟอนต์ น้ำหนัก ขนาด กล่อง และสีแดง/เขียวได้เช่นกัน ร่างยังไม่ถึงจอจนกว่าจะกด **ใช้กับหน้า Score**; ถ้าเซฟไม่สำเร็จแผงจะคืนค่าก่อนแก้ไข กล่องหัวเรื่องเป็นพิกัดบนผืนผ้า 1920×1080 ตรง ๆ ส่วนกล่องตัวเลขเป็นกรอบของตัวเลขในการ์ดของมันเอง ระยะห่างระหว่างตัวแดงกับตัวเขียวเป็นค่าคงที่ใน stylesheet (ยังลากบนกระดานไม่ได้เหมือนโหมดออกอากาศ)

### จอมอนิเตอร์ (`/monitor`)

เปิด `http://127.0.0.1:9779/monitor` ในเบราว์เซอร์ — หน้านี้ไม่เคยว่าง ใช้ดูว่าใครกดแล้ว/ยัง ระหว่างที่จอสตรีมยังสะอาด เครื่องอื่นเปิดได้เฉพาะผ่านลิงก์ **Monitor LAN** ใน dock (หัวข้อถัดไป) ไม่งั้นได้ 403 เพราะหน้านี้เห็นสีก่อนออกอากาศ

แถบบนปักไว้ตลอด: สถานะออกอากาศ รอบและจำนวนโหวต ปุ่ม **แก้ไขโหมด** (เลือกว่าจะจัดเลย์เอาต์โหมดไหน ไม่ได้ส่งขึ้นจอ) รายการชิ้นงาน และปุ่มธง/สถานะของการ์ดที่เลือก เลือกชิ้นที่ไม่ใช่การ์ดแล้วปุ่มจะกดไม่ได้แทนการหายไป ถ้ากำลังแก้โหมดที่ออกอากาศอยู่จะมีแถบเหลืองเตือนว่าคนดูเห็นทันที เครื่องมือที่เหลืออยู่ในแท็บด้านขวา: **ตำแหน่ง**, **ตาราง** (เฉพาะ Show Status), **แม่แบบ**, **PNG สถานะ** หน้าเว็บจำแท็บล่าสุดไว้

หน้าเดียวกันนี้คือตัวจัดตำแหน่งกระดานด้วย:
- แท็บ **แม่แบบ** ด้านขวาเป็น **แม่แบบทุกการ์ด** มีสอง placeholder: PNG ของแต่ละคนและพื้นสีผลธง เลือกเลเยอร์แล้วลาก/ปรับขนาดได้ รวมถึงเลื่อนลำดับหน้า–หลัง ซูมและสีตัวอย่างมีผลเฉพาะตัวแก้ไข
- กด **ใช้แม่แบบกับทุกการ์ด** เพื่อบันทึกและอัปเดต Monitor/Overlay พร้อมกัน การแก้ร่างยังไม่กระทบจอจริง; **ยกเลิกการแก้ไข** คืนค่าที่ใช้ล่าสุด
- แม่แบบใช้กับการ์ดใหม่ด้วยและคงอยู่หลัง Clear/เปิด OBS ใหม่ ตำแหน่งและขนาดรวมของการ์ดแต่ละใบยังคงเดิม
- **คลิกแล้วลากการ์ดแต่ละคนได้อิสระ** ในกรอบ 16:9 มี snap เข้าเส้นกึ่งกลางและเส้นสามส่วน ไม่มีหัวข้อและเลขรอบบนกระดาน
- เปิด/ปิด **เส้นตาราง** ช่องละ 60px ที่แถบซูมบนผืนผ้าใบ ได้เฉพาะ Monitor; ตารางไม่ออก Overlay
- กรอบสีน้ำเงินบอกชิ้นที่เลือก (เห็นเฉพาะ Monitor) เลือกจากรายชื่อได้ด้วยเมื่อการ์ดซ้อนกัน การ์ดท้ายรายชื่ออยู่ด้านหน้า
- มุมขวาบอก **ระยะซ้าย/ขวาของชิ้นที่เลือก** เป็นพิกเซล ขึ้น ✓ เมื่อสมมาตร
- ลูกศรขยับการ์ดทีละ 1px, Shift+ลูกศรทีละ 10px และมีปุ่มกึ่งกลางแนวนอน/แนวตั้ง ปรับตำแหน่งและขนาดพื้นสีในแม่แบบด้านขวาโดยเลือกเลเยอร์พื้นสี; PNG คงเดิม
- ปุ่ม **Layer** จัดการ์ดที่เลือกไปหน้าสุด/ขึ้นหนึ่งชั้น/ลงหนึ่งชั้น/หลังสุดได้; Overlay ใช้ลำดับเดียวกัน
- การ์ดปกติเป็น PNG มีพื้นเทาช่วยจัดวางเฉพาะ Monitor ขณะรอผล; Overlay โปร่งใส เมื่อมีผล สีเขียว/แดงอยู่หลัง PNG และเห็นผ่านส่วนโปร่งใสของภาพ
- **รีเซ็ตชิ้นที่เลือก** กลับไปตำแหน่ง grid เดิม; **รีเซ็ตทั้งหมด** ต้องกดสองครั้งภายใน 3 วินาที แล้วจัด grid ใหม่กลางจอและคืนขนาดเริ่มต้น (ปุ่มรีเซ็ตในแท็บ ตั้งค่า ของ Dock รีเซ็ตแบบเดียวกัน แต่ถามยืนยันด้วยกล่องข้อความก่อนแทนการกดสองครั้ง)
- ปล่อยเมาส์หรือแถบขนาดแล้วบันทึกเอง จอสตรีมขยับตาม หากส่งไม่ได้จะแจ้งและลองส่งใหม่ระหว่างเปิดหน้านี้อยู่
- Clear รอบและเปิด OBS ใหม่ยังจำตำแหน่งที่บันทึกไว้ การเพิ่ม/ลบคนไม่ขยับการ์ดที่จัดไว้แล้ว ส่วนคนที่ยังไม่ได้จัดใช้ grid สูงสุด 3 คนต่อแถวตามเดิม
- session เก่าเปิดต่อได้ทันทีโดยใช้ตำแหน่งกระดานเดิม จนกว่าจะปรับรายชิ้นหรือรีเซ็ตทั้งหมด ทั้งหมดยังใช้ Browser Source `/overlay` เดียวและเปิดผลพร้อมกัน

### Monitor จากเครื่องอื่นใน LAN

1. ใน dock แท็บ **ตั้งค่า → Monitor LAN** ติ๊ก **อนุญาตเครื่องอื่นใน LAN เปิด monitor**
2. กด **คัดลอก** ลิงก์ `http://<IP>:9779/monitor?key=…` แล้วส่งให้คนจัดเลย์เอาต์เท่านั้น เปิดครั้งแรกแล้ว URL จะเหลือ `/monitor` (กุญแจย้ายไปอยู่ใน cookie) ลิงก์ `Score` ใต้กันทำงานแบบเดียวกันและเหลือ `/score`
3. เอาติ๊กออกแค่พักสิทธิ์ LAN ชั่วคราว — กุญแจยังอยู่เหมือนเดิม ติ๊กกลับเมื่อไหร่ลิงก์เดิมก็ใช้ได้อีก ถ้าลิงก์อาจหลุดไปแล้ว หรือจบงานแล้ว ให้กด **สุ่มกุญแจใหม่…** เครื่อง LAN ที่เปิดอยู่จะถูกตัดทันทีและขึ้นแถบแดง `กุญแจถูกเปลี่ยนหรือปิดสิทธิ์แล้ว`

เครื่อง LAN ทำได้ทุกอย่างที่หน้า monitor ทำ **ยกเว้นส่งขึ้นจอหรือเลือกโลโก้** (`/api/display`, `/api/logo` ใช้ได้เฉพาะเครื่องนี้เสมอ) สวิตช์และกุญแจถูกบันทึกใน session ถ้า OBS ปิด-เปิดใหม่ ลิงก์เดิมยังใช้ได้ ใส่กุญแจผิดถูกหน่วง 1 วินาที

ทนหน้างานยังไง:
- โหวตเป็น **idempotent** (มือถือส่ง "สีปัจจุบัน" ไม่ใช่ "เหตุการณ์") ยิงซ้ำกี่ครั้งผลเท่าเดิม
- เน็ตหลุดตอนกด มือถือเก็บไว้แล้วส่งเองเมื่อกลับมา ไม่ต้อง refresh
- OBS ปิด-เปิดใหม่ มือถือ sign-in เองด้วย PIN ที่จำไว้ ไม่เด้งกลับหน้า PIN
- SSE ส่ง heartbeat ทุก 15 วินาที และ `EventSource` reconnect เอง
- หน้ามือถือใช้ธีมเข้ม แสดงชื่อ สำนัก รอบ สถานะเชื่อมต่อ และแยกสถานะกำลังส่ง/ส่งแล้ว/ขาดการเชื่อมต่อ
- **ออก / เปลี่ยน PIN** ถามยืนยันก่อนกลับหน้า PIN ว่าง ผลโหวตที่เซิร์ฟเวอร์รับแล้วอยู่ต่อ การออกยกเลิกการส่งซ้ำและป้องกันคำตอบล่าช้าของบัญชีเดิมกระทบบัญชีใหม่

> ใช้ SSE ไม่ใช่ WebSocket เพราะ obs-deps ไม่ได้ build `qtwebsockets` (มีแค่ qtbase/imageformats/shadertools/multimedia/svg/tools) — `Qt6::Network` ใน qtbase พอสำหรับ QTcpServer อยู่แล้ว

### Hotkeys

ปุ่มบนแถบไลฟ์มี hotkey ของ OBS ให้ทุกปุ่ม ตั้งคีย์เองได้ที่ **OBS → Settings → Hotkeys** (ยังไม่ผูกคีย์ไว้ให้ตั้งแต่แรก — จะได้ไม่ไปชนคีย์ที่ใช้อยู่แล้ว):

| รายการใน Settings → Hotkeys | ทำอะไร |
|---|---|
| `FFF Flag Board: สลับ Show Status ขึ้น/ลงจอ` | เท่ากับกดปุ่ม **Show Status** — กดตอนออกอากาศอยู่แล้วลงจอ |
| `FFF Flag Board: สลับ BOTTOM BAR ขึ้น/ลงจอ` | เท่ากับกดปุ่ม **BOTTOM BAR** |
| `FFF Flag Board: ซ่อนจอ` | เท่ากับกดปุ่ม **■ ซ่อนจอ** |
| `FFF Flag Board: เริ่มรอบใหม่ (ไม่ถามยืนยัน)` | ล้างผลโหวตแล้วขึ้นรอบถัดไป **ทันที** |

ข้อต่างเดียวจากปุ่มคือ **เริ่มรอบใหม่จากคีย์ไม่ถามยืนยัน** — มือ operator อยู่บนคีย์บอร์ด กล่องยืนยันที่มองไม่เห็นแย่กว่าไม่มี ส่วนปุ่ม **↻ เริ่มรอบใหม่…** ใน dock ยังถามเหมือนเดิม ทั้งสองทางล้างผลโหวตอย่างเดียว รายชื่อ PNG และ PIN ยังอยู่ครบ

คีย์ทำงานได้แม้ dock ปิดอยู่หรือโฟกัสอยู่หน้าต่างอื่นของ OBS ตามกติกาของ OBS เอง กดค้างแล้วปล่อยนับเป็นครั้งเดียว

OBS ไม่เซฟคีย์ที่ปลั๊กอินลงทะเบียนให้ ปลั๊กอินจึงเก็บเองที่ `hotkeys.json` ข้าง `session.json` ใน config ของปลั๊กอิน เขียนทุกครั้งที่ OBS เซฟและตอนปิด OBS แล้วอ่านกลับตอนเปิด — คีย์ที่ตั้งไว้อยู่ข้ามการปิด-เปิด และผูกกับเครื่อง ไม่ผูกกับ scene collection

## ตั้งค่าก่อนงาน

1. เปิด OBS → Docks → **FFF Flag Board**
2. แท็บ **รายชื่อ**: กด **+ เพิ่ม** ทีละคนจนครบทุกนายก แก้ชื่อ/สำนักวิชาในตารางได้เลย เลือกแถวแล้วใช้เมนู **PNG** เพื่อใส่การ์ด BOTTOM BAR หรือโลโก้ (ไฟล์ถูก copy เข้า config ของปลั๊กอิน ไฟล์ต้นทางย้ายได้) คอลัมน์ การ์ด/BAR/โลโก้ ขึ้น ✓ เมื่อมีไฟล์
3. PIN สุ่มให้อัตโนมัติ 6 หลัก ใช้เมนู **⋯ → สุ่ม PIN ใหม่…** ถ้าอยากเปลี่ยน (ถามยืนยันก่อน มือถือที่เข้าอยู่แล้วยังใช้ต่อได้) — แจก PIN ให้คนดูคนละตัว
4. เพิ่ม **Browser Source** ชี้ `http://127.0.0.1:9779/overlay`
   - **ขนาดต้องเป็น 1920×1080 และ transform ต้องรีเซ็ต** — หน้า overlay เป็น canvas เต็มจอ ตำแหน่งการ์ดและหัวข้อจัดจากหน้ามอนิเตอร์
   - **ปิด "Shutdown source when not visible" และ "Refresh browser when scene becomes active" ทั้งคู่** ไม่งั้น SSE จะโดนตัดตอนสลับ scene
5. คนดูเปิดเบราว์เซอร์มือถือไปที่ `http://<IP ของ Mac>:9779` (แท็บ **ตั้งค่า** ใน dock บอก IP ให้ กดปุ่ม **คัดลอก** ข้าง URL ได้เลย)
6. เปิด `http://127.0.0.1:9779/monitor` ไว้อีกหน้าต่าง หรือส่งลิงก์ Monitor LAN ให้คนจัดเลย์เอาต์ เลือกการ์ดหรือหัวข้อแล้วลากและปรับขนาดตามต้องการ

Checklist หน้างาน:
- **Mac ห้ามหลับ** — `caffeinate -d` หรือตั้ง Energy Saver
- ทดสอบบน router ตัวที่จะใช้จริง ไม่ใช่ Wi-Fi บ้าน — Wi-Fi สาธารณะบางที่เปิด client isolation แล้วมือถือจะคุยกับ Mac ไม่ได้
- ตั้ง DHCP reservation ให้ Mac ไม่งั้น IP เปลี่ยนแล้วคนดูเข้าไม่ได้
- บอกคนดูให้ตั้งมือถือไม่ให้ล็อกหน้าจอ (หน้าเว็บขอ wake lock ให้แล้ว แต่ไม่ใช่ทุกเบราว์เซอร์รองรับ)

Smoke test หลังติดตั้งเวอร์ชันใหม่ (ใน OBS จริง):
- ลาก dock ให้แคบประมาณ 320px แถบไลฟ์และปุ่มยังอ่านได้ ไม่ถูกตัด
- ระหว่าง BOTTOM BAR ออกอากาศ สลับ Round 1 / Round 2 แล้วโลโก้กลางต้องเปลี่ยนทันที เลือกสำนักที่ไม่มี PNG Round 2 แล้วต้องมีคำเตือน
- กด Show Status / BOTTOM BAR / ■ ซ่อนจอ แล้วดู Browser Source เปลี่ยนตาม กดโหมดที่ออกอากาศซ้ำแล้วต้องลงจอ; กด ↻ เริ่มรอบใหม่… แล้วกดยกเลิกหนึ่งครั้ง ยืนยันหนึ่งครั้ง
- ตั้งคีย์ทั้งสี่ใน Settings → Hotkeys แล้วกดทีละตัว: ผลต้องตรงกับปุ่มของมัน, คีย์เริ่มรอบใหม่ต้องไม่มีกล่องยืนยัน, กดค้างแล้วปล่อยต้องทำงานครั้งเดียว; ปิด-เปิด OBS แล้วคีย์ยังอยู่
- เปิด Monitor LAN จากโน้ตบุ๊กหรือมือถืออีกเครื่องผ่านลิงก์ใน dock ลากการ์ดได้ แล้วกด สุ่มกุญแจใหม่… เครื่องนั้นต้องขึ้นแถบแดง
- ส่งลิงก์ Monitor LAN ผ่านแอปแชทหรือเว็บแชทไปยังเครื่องที่สอง เปิดลิงก์นั้นครั้งแรกต้องไปจบที่หน้ามอนิเตอร์ให้ได้ (หน้าปฏิเสธรีโหลดให้เองครั้งเดียว)
- เพิ่ม monitor เป็น Custom Browser Dock ใน OBS แล้วลอง รีเซ็ตทั้งหมด แบบกดสองครั้ง

ข้อจำกัดที่ต้องรู้: ไม่มี TLS และเป็น LAN ปิดของทีม ใครอยู่ในวงเดียวกันแล้วเดา PIN ถูกก็โหวตแทนได้ — PIN สุ่ม 6 หลัก และคำขอที่ PIN ผิดถูกหน่วง 1 วินาที ฟีด overlay/monitor ให้เฉพาะ 127.0.0.1 หรือเครื่องที่ถือกุญแจ Monitor LAN เพราะเห็นผลก่อนเปิด — กุญแจวิ่งผ่าน HTTP ธรรมดา ใครดักแพ็กเก็ตใน Wi-Fi เดียวกันได้ก็เห็นกุญแจ ใช้เฉพาะ Wi-Fi ของทีม และสุ่มกุญแจใหม่หลังจบงาน ลิงก์ที่มีกุญแจยังค้างอยู่ในประวัติเบราว์เซอร์ของเครื่องที่เปิดมันครั้งแรกด้วย ถ้าเครื่องนั้นเป็นเครื่องใช้ร่วมกันให้สุ่มกุญแจใหม่ คุกกี้สิทธิ์ monitor ก็ไม่ได้ผูกกับพอร์ต เปลี่ยนพอร์ตเซิร์ฟเวอร์แล้วคุกกี้เดิมยังใช้เปิดได้อยู่

## Build บน macOS (เครื่องพัฒนา)

ต้องมี: Xcode 16 ตัวเต็มจาก App Store (ไม่ใช่แค่ Command Line Tools), CMake (`brew install cmake`), OBS Studio

```sh
# ครั้งแรก หรือหลังแก้ CMakeLists/buildspec/เพิ่มไฟล์ใน data/ (ดาวน์โหลด libobs+Qt ครั้งแรกจะนานหน่อย)
cmake --preset macos

# ทุกครั้งที่แก้โค้ด: build + ติดตั้งลง OBS + เซ็น ad-hoc ในคำสั่งเดียว
./dev-install.sh
```

แล้วปิด-เปิด OBS ใหม่ ดูใน log (Help → Log Files → View Current Log) ต้องเจอ:

```
[fff-tools] plugin loaded successfully (version 0.3.0)
[fff-tools] flag board listening on port 9779
```

ถ้า cmake บ่นว่าไม่พบ generator "Xcode": `sudo xcode-select -s /Applications/Xcode.app`

`data/` ถูก glob ตอน configure — เพิ่มไฟล์ใหม่ใน `data/web/` ต้องรัน `cmake --preset macos` ซ้ำ แก้เนื้อไฟล์เดิมไม่ต้อง

## Build OS อื่น

- **Windows**: `cmake --preset windows-x64` แล้ว `cmake --build --preset windows-x64 --config RelWithDebInfo` (ต้อง VS2022 + Windows SDK 10.0.22621)
- **Ubuntu 24.04**: `cmake --preset ubuntu-x86_64` แล้ว `cmake --build --preset ubuntu-x86_64`
- หรือ push ขึ้น GitHub แล้วให้ Actions build ทั้ง 3 OS ให้ (ดูแท็บ Actions → Artifacts)

## ออกเวอร์ชันใหม่

1. แก้ `"version"` ใน `buildspec.json` — ชื่อไฟล์ทุกตัวมาจากที่นี่ **tag ไม่ได้ป้อนเวอร์ชันให้ build**
2. commit แล้ว merge เข้า `main`
3. `git tag 0.3.0 && git push origin 0.3.0` (รับ `v0.3.0` ด้วย ตัว `v` ถูกตัดทิ้ง) — ถ้า tag ไม่ตรงกับ `buildspec.json` workflow จะล้มพร้อมบอกเหตุผล
4. Actions build ทั้ง 3 OS แล้วสร้าง **draft release** พร้อมไฟล์แนบไว้ — เข้าไปตรวจแล้วกด Publish เอง

## โครงโค้ด

- `src/plugin-main.c` — จุดเริ่ม ลงทะเบียน filter + dock
- `src/fff-session.h/.cpp` — รายชื่อนายก, โหวตของรอบปัจจุบัน, state machine, โหลด-เซฟ `session.json`
- `src/fff-http-server.h/.cpp` — HTTP + SSE server (QTcpServer) เสิร์ฟหน้าเว็บ รับโหวต push สถานะ
- `src/fff-dock.cpp` — ประกอบ dock: แถบไลฟ์ + แท็บ; `fff-dock-live` (แถบไลฟ์และแท็บไลฟ์), `fff-dock-roster` (แท็บรายชื่อ), `fff-dock-settings` (แท็บตั้งค่า), `fff-dock-ui.h` (สีและกล่องยืนยัน)
- `src/fff-monitor-access.h/.cpp` — กฎล้วนว่าใครเปิด monitor จาก LAN ได้ (กุญแจ, cookie, ประเภท endpoint)
- `src/fff-hotkeys.h/.cpp` — hotkey ของ OBS สำหรับปุ่มบนแถบไลฟ์ + เซฟ/คืนค่า binding ที่ `hotkeys.json`
- `data/web/` — `phone.html` (หน้าคนดู), `overlay.html` (จอสตรีม), `score.html` (จอนับธงสด), `monitor.html` (จอ operator + จัดตำแหน่ง), `board.js` (ตัววาดกระดานและตัวนับที่ทุกหน้าใช้ร่วมกัน), `app.css`
- `src/tint-filter.c` — ตัวอย่าง video filter (คู่กับ `data/tint.effect` ซึ่งเป็น shader)
- `buildspec.json` — ชื่อ/เวอร์ชัน plugin และเวอร์ชัน OBS ที่ build ด้วย

โค้ด C/C++ ใช้ tab (clang-format, IndentWidth 8) — `dock`, `session`, `http-server` compile เฉพาะตอน `ENABLE_QT` และ `ENABLE_FRONTEND_API` เปิดทั้งคู่ (preset เปิดให้แล้ว)

ข้อมูลตอนใช้งานเก็บที่ `~/Library/Application Support/obs-studio/plugin_config/fff-tools/` (`session.json` + `cards/`)
